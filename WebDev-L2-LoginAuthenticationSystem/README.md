## 🔐  Login Authentication System

A simple and secure Login Authentication System developed using web technologies. This project allows users to create an account, log in, and access a dashboard.

## 📌 About the Project

SecureGate is a web-based authentication system designed to provide a simple and user-friendly login experience. It includes account creation, user login, and a dashboard.

## ✨ Features

- 🔑 User Login
- 📝 Create Account
- 🔒 Password Authentication
- 📊 User Dashboard
- 🚪 Logout Functionality
- 🎨 Simple and Responsive Design
- 🛡️ User-Friendly Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Outcome

This project demonstrates the basic concepts of web development and user authentication using HTML, CSS, and JavaScript. It provides users with a simple interface for creating an account, logging in, accessing a dashboard, and logging out.
